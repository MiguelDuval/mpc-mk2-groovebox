# MPC Studio MkII Groovebox

Android standalone-style groovebox centered on the Akai MPC Studio MkII, using Tracktion Engine + JUCE + Oboe with Ableton Link integration planned.

The project targets an MPC One/One+ style hardware-oriented workflow rather than an MPC Desktop clone.

Status: architecture/bootstrap.
